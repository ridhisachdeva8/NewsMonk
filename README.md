# 📰 NewsMonk

NewsMonk is a React-based news application that allows users to explore news across different categories, including Business, Entertainment, General, Health, Science, Sports, and Technology.

## ✨ Features

- Browse news by category
- Navigate between different news sections
- News fetching using NewsAPI
- Responsive navigation interface

## 🛠️ Tech Stack

- React.js
- JavaScript
- React Router
- Bootstrap / CSS
- NewsAPI

## 🌐 Live Demo

[View NewsMonk](https://ridhisachdeva8.github.io/NewsMonk/)

**Note:** The deployed version currently has a limitation with NewsAPI because the Developer plan restricts browser requests from deployed domains. News articles may not load on the live demo.

## 🚀 Getting Started

### Prerequisites

- Node.js
- pnpm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ridhisachdeva8/NewsMonk.git
   ```

2. Navigate to the project directory:

   ```bash
   cd NewsMonk
   ```

3. Install dependencies:

   ```bash
   pnpm install
   ```

4. Start the development server:

   ```bash
   pnpm start
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
